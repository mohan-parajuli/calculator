# Simple Calculator

## Project Description
This project is a simple calculator built with HTML, CSS, and JavaScript. It allows users to perform basic arithmetic operations like addition, subtraction, multiplication, and division. The application has a user-friendly interface designed for ease of use.

## Features
- Perform basic arithmetic operations (addition, subtraction, multiplication, and division)  
- Clear input and output fields  
- Responsive design for mobile and desktop users  
- Easy to use and understand interface  

## Technologies Used
- **HTML** (52.3%) - Markup structure
- **CSS** (28.3%) - Styling and layout
- **JavaScript** (19.4%) - Functionality and interactivity

## Installation
To run this project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/mohan-parajuli/calculator.git
   ```

2. Navigate to the project directory:
   ```bash
   cd calculator
   ```

3. Open `index.html` in your web browser.

## Usage
1. Enter the first number in the input field
2. Select an operation (+, -, *, /)
3. Enter the second number
4. Click the equals button (=) to get the result
5. Use the clear button (C) to reset the calculator for a new calculation
